## Overview

This site is my portfolio. It is themed as a Hong Kong cha chaan teng (茶餐廳). Each project is an item on the menu. Visitors can tick items on a paper order slip, check out and get a receipt.

## Process

- Built with Astro as a static site
- Each project, book and video is one Markdown file, checked against a typed schema
- Hand-written CSS with design tokens, no CSS framework
- The order slip and photo lightbox are small React islands
- Hosted on Cloudflare Pages
